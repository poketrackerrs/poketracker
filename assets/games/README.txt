GAME BOX ART
============

Drop a box-art image in this folder for each game, named by its ID with a
.png extension. Any game whose file is missing simply shows a styled fallback
card, so you can add art gradually.

Recommended: portrait box art, roughly 300x450px or larger, PNG.

Expected filenames:

  rby.png    -> Red / Blue / Yellow
  gsc.png    -> Gold / Silver / Crystal
  rse.png    -> Ruby / Sapphire / Emerald
  frlg.png   -> FireRed / LeafGreen
  dppt.png   -> Diamond / Pearl / Platinum
  hgss.png   -> HeartGold / SoulSilver
  bw.png     -> Black / White
  b2w2.png   -> Black 2 / White 2
  xy.png     -> X / Y
  oras.png   -> Omega Ruby / Alpha Sapphire
  sm.png     -> Sun / Moon
  usum.png   -> Ultra Sun / Ultra Moon
  lgpe.png   -> Let's Go Pikachu / Eevee
  swsh.png   -> Sword / Shield
  bdsp.png   -> Brilliant Diamond / Shining Pearl
  sv.png     -> Scarlet / Violet
  pla.png    -> Legends: Arceus
  lza.png    -> Legends: Z-A

After adding files, no rebuild of the code is needed for a debug run
(hot restart picks them up); for the release .exe, rebuild once.
