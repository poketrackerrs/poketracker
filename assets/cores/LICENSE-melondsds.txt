melonDS DS (libretro core) — bundled binary
============================================

This application bundles the melonDS DS libretro core
(melondsds_libretro), which emulates the Nintendo DS. It is built on the
melonDS emulator.

  melonDS DS (libretro core):  https://github.com/JesseTG/melonDS-ds
  melonDS emulator:            https://github.com/melonDS-emu/melonDS

changes were made to it.
